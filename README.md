Recovered Gorilla Studio / MAKE-A-RENDER-READER source backup.

Download and extract `MAKE-A-RENDER-READER_Source_Publishing.zip`. The `MAKE-A-RENDER-READER` folder inside contains the application source, tests, tooling, documentation, and updater metadata. The export also includes a source manifest and restoration notes.

This is a Windows desktop application source snapshot, not a GitHub Pages website or an installable application release. Game data, original application binaries, and release ZIPs are excluded. Existing download URLs in the snapshot have not been verified or restored.
