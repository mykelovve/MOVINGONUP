AEW 2025 (Titavius) - ALL SIX MOVING MATCH CARDS
  All Out 25, Double or Nothing 25, Forbidden Door 25, Full Gear 25, Worlds End 25, WrestleDream 25
Moving types: 1on1, 2on2, triple threat, fatal 4-way (every card <= 16 movies, all slots checked).

INSTALL
1. Close WWE.
2. Extract this zip anywhere (e.g. Desktop).
3. Right-click Install_AEW2025_Cards.ps1 > Run with PowerShell (or open PowerShell as Administrator and run it).
   For each card it finds the original of the same name in discovery_data, keeps it as .bak,
   puts the moving card there, and copies it to the same path inside TITAVUSREVATCHCARD.
   Any line saying NOT FOUND / MORE THAN ONE: send me that output.
4. Bake TITAVUSREVATCHCARD, keep only the newest TITAVUSREVATCHCARD .cak in mods, restart WWE.

If PowerShell refuses to run scripts, first run once:  Set-ExecutionPolicy -Scope Process Bypass
