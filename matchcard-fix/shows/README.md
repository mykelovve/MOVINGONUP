# Set 01 for other shows

Each card gets moving portraits for **1on1, 2on2, triple threat and fatal four-way** (13 clips).
These cards had no movie layers at all, so each new layer is a copy of Dynamite's working
one-on-one layer, pointed at that slot's placeholder movie. Each card has 14 movies in total
(13 clips plus its `bg`), under the plugin's 16.

| `SummerSlam26_Set01.zip` | SummerSlam 2026 (Rev's arena) | `Arena/Rev's_Arenas/SUMMERSLAM_2026/Data/matchup.jsfb` |
| `AllOut19_Set01.zip` | AEW All Out 2019 | the same folder your `matchup_allout_19.jsfb` came from |

**SummerSlam warning:** this is the same source card as the earlier SummerSlam test, which crashed
WWE at launch. The cause was never found. Test it **on its own**, keep your working CAK backed up,
and put the backup back if the game crashes at launch.
